Changelog

更新日志

记录海心云 MQ 管理台的功能、运维能力与部署变化。当前 Docker Hub 已发布版本仍为 2.1.2， 下列 2.1.3 内容处于待发布状态。

2.1.3

待发布 Unreleased

多集群与管理

  • 多集群切换：登录选择集群，顶栏和后台均可切换，凭据按目标集群重新校验。
  • 管理对象：vhosts、users、permissions、policies、parameters、nodes、feature flags。
  • Shovel / Federation：只读查看运行状态。
  • Definitions：导入/导出 RabbitMQ definitions。

消息与拓扑

  • 消息运维：筛选、移动/重放到队列或交换机，支持 DLQ 后缀预填与失败退回源队列。
  • 拓扑图：交换机、队列、绑定关系可视化，支持搜索与 vhost 范围。
  • 批量操作：队列批量清空/删除，带 dry-run 预览和逐队列结果。
  • 消费者：队列详情支持远程取消消费者。

运维与安全

  • 告警：钉钉/飞书/企微/Slack/Teams/Telegram 预设、升级通道、1/4/24 小时静默、Runbook URL。
  • 审计与角色：审计筛选/CSV 导出、本地角色覆盖、双人审批。
  • 可靠性：SQLite WAL、每日备份、暂存式恢复、小时降采样、启动完整性检查。
  • 可观测性：Prometheus /api/metrics、活动告警铃铛、PWA manifest。
  • 安全：同源写校验、登录限流、安全响应头、npm audit/Trivy/CodeQL 流水线。

体验

  • 队列收藏与命名视图；拓扑、批量操作和通知中心。
  • 依赖升级：Next.js 16.4.3、React 19.3、motion 14、nodemailer 10；依赖审计 0 漏洞。
